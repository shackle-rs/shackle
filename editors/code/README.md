# MiniZinc Language Support

This extension adds MiniZinc language support powered by the Shackle Language Server.

Currently experimental, and targets the next major MiniZinc language version, which may be incompatible with current models.

## Features

- Syntax highlighting, including semantic token highlighting for distinguishing par/var identifiers
- Diagnostic reporting for syntax/type errors
- Types on hover
- Inlay hints for call argument names
- Safe renaming of symbols
- Goto definition
- Find references
- Code completion
- Code formatting
